# Experiment 4: CSS Box Model, Normal Flow, and CSS3

## Aim
Build a simple layout and examine how the box model affects element dimensions.

## Steps
1. Add two content sections to an HTML page.
2. Set width, padding, border, and margin on one section.
3. Compare the default box model with `box-sizing: border-box`.
4. Add a CSS3 feature such as a shadow or transition.

## Example
```css
.card {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
  margin: 16px;
  box-shadow: 2px 2px 8px #aaa;
}
```

## Result
Created a layout using normal flow and demonstrated the CSS box model.
