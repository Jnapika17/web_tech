# Experiment 2: XHTML/HTML Elements, Relative URLs, Lists, Tables, Frames, and Forms

## Aim
Create a structured page using common HTML elements.

## Steps
1. Create a valid HTML document with headings and paragraphs.
2. Add a list, a table, and a link to another local page using a relative URL.
3. Create a form with labeled input fields and a submit button.
4. If demonstrating frames, use an `iframe` to embed a local page.

## Example
```html
<h1>Student Details</h1>
<a href="about.html">About</a>
<ul><li>HTML</li><li>CSS</li></ul>
<form><label>Name <input name="name"></label><button>Submit</button></form>
```

## Result
Created a page demonstrating links, lists, tables, embedded content, and forms.
