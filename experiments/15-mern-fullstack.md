# Experiment 15: MERN Full-Stack Application

## Aim
Build a simple application integrating MongoDB, Express, React, and Node.js.

## Steps
1. Create an Express/Node.js backend and connect it to MongoDB.
2. Add an API endpoint that reads or writes application data.
3. Build a React frontend that calls the API.
4. Run frontend and backend, then verify the complete request flow.

## Application Flow
React UI → HTTP request → Express/Node.js API → MongoDB

## Result
Connected a React frontend to an Express API backed by MongoDB.
