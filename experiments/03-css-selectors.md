# Experiment 3: CSS Selectors, Style Rules, Cascading, Inheritance, and Text

## Aim
Style a page and observe selector matching, inheritance, and the cascade.

## Steps
1. Create a page with headings and paragraphs.
2. Apply element, class, and ID selectors.
3. Set inherited text styles on `body`, then override a property on a child.
4. Change competing rules and observe which declaration wins.

## Example
```css
body { font-family: Arial, sans-serif; color: #333; }
.notice { color: navy; }
#title { text-align: center; }
```

## Result
Applied CSS style rules and observed text styling and cascading behavior.
